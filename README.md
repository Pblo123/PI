# Cómo actualizar el sistema
#### A continuación se mostrará una serie de instrucciones para la actualización manual de un sistema linux...

### __Objetivos principales:__
1. Familiarizarse en el entorno operativo de Linux.
2. Conocer de primera mano los comandos correspondientes.
3. Encontrar en Linux una comodidad inigualable :).

### __Instalación__

##### Actualizar paquetes:
```sudo apt update```  

Fuente:  [Instituto Linux](https://www.institutolinux.com/instalar-actualizar-y-eliminar-software/).

- [x] Tener alguna distribución de Linux
